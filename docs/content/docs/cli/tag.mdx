Label projects and filter the dashboard by tag.

`discord-enterprise tag` exposes **8 commands**. They map one-to-one onto the `tag.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise tag --help` to list these commands in your terminal, or
	`discord-enterprise tag <command> --help` for a single command.
</Callout>

## Commands
