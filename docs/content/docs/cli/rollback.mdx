Roll a deployment back to a previously built image.

`discord-enterprise rollback` exposes **2 commands**. They map one-to-one onto the `rollback.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise rollback --help` to list these commands in your terminal, or
	`discord-enterprise rollback <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise rollback delete`

Calls `POST /api/trpc/rollback.delete`.

```bash
discord-enterprise rollback delete --rollbackId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--rollbackId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |

### `discord-enterprise rollback rollback`

Calls `POST /api/trpc/rollback.rollback`.

```bash
discord-enterprise rollback rollback --rollbackId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--rollbackId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
