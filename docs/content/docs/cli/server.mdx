Add remote servers over SSH, validate them and read their metrics and services.

`discord-enterprise server` exposes **21 commands**. They map one-to-one onto the `server.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise server --help` to list these commands in your terminal, or
	`discord-enterprise server <command> --help` for a single command.
</Callout>
