Add and remove Swarm workers and managers.

`discord-enterprise cluster` exposes **4 commands**. They map one-to-one onto the `cluster.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise cluster --help` to list these commands in your terminal, or
	`discord-enterprise cluster <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise cluster add-manager`

Calls `GET /api/trpc/cluster.addManager`.

```bash
discord-enterprise cluster add-manager [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | No | — |
| `--profile <name>` | string | No | — |
