Aggregated counters for the dashboard: services, backups and domains.

`discord-enterprise overview` exposes **3 commands**. They map one-to-one onto the `overview.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise overview --help` to list these commands in your terminal, or
	`discord-enterprise overview <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise overview backups`

Calls `GET /api/trpc/overview.backups`.

```bash
discord-enterprise overview backups [options]
```
