Per-application HTTP basic auth and response security headers.

`discord-enterprise security` exposes **4 commands**. They map one-to-one onto the `security.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise security --help` to list these commands in your terminal, or
	`discord-enterprise security <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise security create`

Calls `POST /api/trpc/security.create`.

```bash
discord-enterprise security create --applicationId <value> --username <value> --password <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--applicationId <value>` | string | Yes | — |
| `--username <value>` | string | Yes | — |
| `--password <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
