Inspect Docker Swarm nodes, node workloads and container statistics.

`discord-enterprise swarm` exposes **5 commands**. They map one-to-one onto the `swarm.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise swarm --help` to list these commands in your terminal, or
	`discord-enterprise swarm <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise swarm get-console`
