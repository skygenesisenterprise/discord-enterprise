Containers, the Docker daemon configuration, events and container files.

`discord-enterprise docker` exposes **20 commands**. They map one-to-one onto the `docker.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise docker --help` to list these commands in your terminal, or
	`discord-enterprise docker <command> --help` for a single command.
</Callout>
