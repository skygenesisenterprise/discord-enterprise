Custom TLS certificates loaded by Traefik alongside automatic Let's Encrypt ones.

`discord-enterprise certificates` exposes **8 commands**. They map one-to-one onto the `certificates.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise certificates --help` to list these commands in your terminal, or
	`discord-enterprise certificates <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise certificates all`

Calls `GET /api/trpc/certificates.all`.

```bash
discord-enterprise certificates all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |
