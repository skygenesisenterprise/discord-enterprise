Applications and databases live inside an environment, and environments belong to a project.

`discord-enterprise environment` exposes **7 commands**. They map one-to-one onto the `environment.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `discord-enterprise environment --help` to list these commands in your terminal, or
	`discord-enterprise environment <command> --help` for a single command.
</Callout>

## Commands

### `discord-enterprise environment by-project-id`

Calls `GET /api/trpc/environment.byProjectId`.

```bash
discord-enterprise environment by-project-id --projectId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--projectId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
