---
title: Uninstall
description: "Learn how to uninstall Discord Enterprise on your server"
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

Follow these steps to completely remove Discord Enterprise and its components from your server.

<Steps>
<Step>
Remove the docker swarm services created by Discord Enterprise:

   ```bash
   docker service remove discord-enterprise discord-enterprise-traefik discord-enterprise-postgres discord-enterprise-redis
   docker container remove -f discord-enterprise-traefik
   ```
 
</Step>
 
<Step>
 
Remove the docker volumes created by Discord Enterprise:

   ```bash
   docker volume remove -f discord-enterprise discord-enterprise-postgres discord-enterprise-redis
   ```
 
</Step>

<Step>
 
Remove the docker network created by Discord Enterprise:

   ```bash
   docker network remove -f discord-enterprise-network
   docker network remove -f ingress
   ```
 
</Step>

<Step>

If you were running a Cluster, then for each worker node, remove all it's services and make it leave the swarm:

   ```bash
   docker service rm $(docker service ls -q)
   docker system prune -a -f
   docker swarm leave
   ```
</Step>

<Step>

Make the manager node (where Discord Enterprise is installed) leave the swarm (run it on all manager nodes if you had more than one):

   ```bash
   docker swarm leave --force
   ```
</Step>

<Step>

Docker cleanup to remove leftovers:

   ```bash
   docker container prune --force
   docker image prune --all --force
   docker volume prune --all --force
   docker builder prune --all --force
   docker system prune --all --volumes --force
   ```
 
</Step>
 
<Step>

Remove the discord-enterprise files and directories from your server:

   ```bash
   sudo rm -rf /etc/discord-enterprise
   ```
 
</Step>
</Steps>
